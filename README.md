# Sadaiv Music

Private Android music app with local playback, Jam listen-along, Watch Together, secure chat, secure calls, ringtone tools, lyrics, playlists, widgets, and privacy-focused app modes.

**Download:** [APK](https://github.com/sunnysing1202/sadaiv-music/releases/download/v1.0.0/sadaiv-music.apk)

> This is a private project. This guide is only for installing and using the app.

## Quick Install

1. Download the APK from the link above.
2. Open the APK on your Android phone.
3. If Android asks, allow **Install unknown apps** for the app you used to open the APK.
4. Install Sadaiv.
5. Open the app and grant the permissions needed for the features you want to use.
6. Let the app scan your local music library.

## Requirements

- Android 8.0 or newer.
- Local music files for the music player.
- Local video files for Watch Together.
- Internet for Jam long-distance rooms, Watch Together room sync, private chat, calls, profile photos, notifications, and online lyrics.
- Bluetooth/Nearby permissions for nearby Jam.

## Main Features

### Local Music Player

- Browse local songs, albums, artists, folders, playlists, and liked songs.
- Play music already stored on your phone.
- Use recently played, most played, favorite songs, received songs, albums, and dynamic mixes from Home.
- Shuffle the full library.
- Like songs and collect them in Liked Songs.
- Create playlists and add songs to them.
- Search by song, artist, or album.
- Edit display metadata for songs when needed.

### Full Player

- Play, pause, previous, next, seek, shuffle, and repeat.
- Swipe album art left or right to change songs.
- Swipe down on album art to close the player.
- Open queue, lyrics, Jam, or song options.
- Change playback speed.
- Set a sleep timer.
- View Bluetooth, wired, USB, or device audio route.
- Share the current song.
- Open ringtone tools from a song.

### Queue

- See the current song and upcoming songs.
- Jump to another song in the queue.
- Reorder upcoming songs.
- Remove songs from the queue.
- Toggle shuffle.

### Lyrics

- Supports synced LRC lyrics and plain lyrics.
- Reads embedded lyrics from audio files.
- Reads sidecar `.lrc` files when available.
- Can fetch lyrics online and cache them.
- Auto-scrolls synced lyrics while music plays.
- Tap synced lyrics to seek to that line.
- Open full lyrics view.
- Share lyrics as text.

### Equalizer And Audio Effects

- 10-band equalizer.
- Presets.
- Bass boost.
- Virtualizer.
- Gapless playback.
- Crossfade control.

### Ringtone Cutter

- Trim any local song.
- Preview the selected section.
- Add fade in/out.
- Save as ringtone, notification, or alarm.
- Optionally set as the default system sound.

Android may ask for Modify system settings before setting a default ringtone, notification, or alarm.

### YouTube Ringtone Cutter

- Paste a YouTube link.
- Fetch/extract audio.
- Trim the part you want.
- Save it as ringtone, notification, or alarm.

Use only content you have rights to use and follow platform terms.

### Playlist Import And Audio Splitting

- Create playlists manually.
- Import playlist text and match songs from your local library.
- Split long audio mixes into multiple tracks.
- Save matched or split tracks into a playlist.

### Jam Listen-Along

Jam lets friends listen to music together.

- Start a Jam and share a 6-digit code.
- Join a Jam with a 6-digit code.
- Long-distance Jam uses internet sync.
- Nearby Jam uses Bluetooth/Wi-Fi nearby discovery.
- Host and listener roles.
- Host can approve or reject join requests.
- Syncs play/pause, seek, current song, and queue position.
- Shows sync health and song readiness.
- Request a missing song from the host.
- Transfer a song file when both people agree.
- Received Jam songs appear in the app.
- Jam haptics for friend joined, connected, sync locked, remote play/pause/next, queue added, and song received.
- Couples Touch: touch, hold, sparkle, fire, and wave.

### Watch Together

Watch Together lets friends watch local videos in sync.

- Pick a local video.
- Host a room and share the 6-digit room code.
- Join by entering a code or scanning a QR code.
- Syncs video play/pause, seek, position, and playback speed.
- Fullscreen theater mode.
- Brightness and volume gestures.
- Skip forward/back controls.
- Zoom-to-fill option.
- Pause when a friend buffers.
- Optionally allow friends to control playback.
- In-room text chat.
- Reactions and animated theater effects.
- Pointer and drawing overlays.
- Request or transfer the movie file if someone does not have it.

## How To Use

### Play Music

1. Open Sadaiv.
2. Grant music/media permission.
3. Wait for the library scan.
4. Tap a song from Home, Search, Songs, Albums, Artists, Folders, or Playlists.
5. Use the mini player or full player for controls.

### Create A Playlist

1. Open Library.
2. Open Playlists.
3. Create a playlist.
4. Add songs from song options.
5. Open the playlist to play or manage it.

### Start A Jam

1. Play a song.
2. Open the full player.
3. Open Jam.
4. Tap Start Jam.
5. Share the 6-digit code.
6. Approve join requests if prompted.

### Join A Jam

1. Open Jam.
2. Tap Join Jam.
3. Enter the 6-digit code.
4. If you do not have the current song, request it from the host.

### Start Watch Together

1. Open Watch Together.
2. Pick a local video.
3. Tap Host.
4. Share the room code or QR.
5. Use fullscreen mode for the theater controls.

### Join Watch Together

1. Open Watch Together.
2. Enter the room code or scan QR.
3. Pick the same video if you have it.
4. If you do not have it, request the movie file from the host.

### Use Secure Chat

1. Open Chat.
2. Sign in with Google.
3. Set your username.
4. Add or accept friends.
5. Start a chat, group, or call.
6. Open Trust Center for privacy controls.

### Make A Ringtone

1. Open song options.
2. Open Ringtone Cutter.
3. Select the part of the song you want.
4. Preview it.
5. Save as ringtone, notification, or alarm.

## Permissions

Some permissions are optional and only used when a feature needs them.

| Permission | Why It Is Used |
| --- | --- |
| `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` | Read local songs |
| `READ_MEDIA_VIDEO` | Pick local videos |
| `READ_MEDIA_IMAGES` | Select profile/chat images |
| `INTERNET` | Jam, Watch Together sync, chat, calls, online lyrics |
| `POST_NOTIFICATIONS` | Playback, chat, and call notifications |
| `FOREGROUND_SERVICE` | Background playback and calls |
| `RECORD_AUDIO` | Voice messages and calls |
| `CAMERA` | Video calls, QR scanning, profile photos |
| `MODIFY_AUDIO_SETTINGS` | Equalizer and audio routing |
| `WRITE_SETTINGS` | Set ringtone, notification, or alarm |
| Bluetooth/Nearby permissions | Nearby Jam and local discovery |
| `VIBRATE` | Jam haptics |
| `WAKE_LOCK` | Keep playback/session features active |
| `USE_FULL_SCREEN_INTENT` | Incoming call screen |
| `RECEIVE_BOOT_COMPLETED` | Restore scheduled chat messages |

## Privacy Notes

- The music player reads songs from your phone.
- Watch Together reads videos from your phone.
- Online rooms use only the information needed to sync playback and participants.
- Chat content is designed to be encrypted before delivery.
- Calls use WebRTC; relay servers help connect calls but do not need plaintext media.
- Jam or Watch file transfer should only be used with people you trust.
- If someone saves shared media outside the app, Sadaiv cannot delete that external copy.

## Troubleshooting

### No Songs Appear

- Grant media permission.
- Open Settings and tap Rescan Library.
- Disable Clean Music Library temporarily.
- Add your folder to Included Folders.
- Lower Minimum Track Duration.

### Songs Are Hidden

Open Settings, review Excluded Audio, and adjust Hidden Folders, Included Folders, Include Downloads, or Clean Music Library.

### Lyrics Do Not Show

- Check internet for online lyrics.
- Fix song title/artist metadata.
- Add a sidecar `.lrc` file.
- Reopen the player and try again.

### Jam Is Not Syncing

- Check both devices have internet for Long-distance Jam.
- Use Nearby mode only when both devices are close.
- Make sure the code is correct.
- Request/send the missing song if the listener does not have it.
- Use Resync from Jam tools.

### Watch Together Does Not Join

- Confirm the 6-digit code.
- Check internet.
- Pick the same video or request it from the host.
- Reopen the room if the session is stale.

### Chat Sign-In Fails

- Check internet.
- Try signing out and signing in again.
- Make sure Google sign-in is available on the device.

### Calls Do Not Connect

- Grant microphone/camera permissions.
- Check internet.
- Try again on a stronger network.
- Make sure both people are signed in and available.

### Ringtone Cannot Be Set

Grant Modify system settings access when Android asks, then save or set the tone again.
