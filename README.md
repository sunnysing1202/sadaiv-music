# Sadaiv Music

Local music player for Android with Watch Together and Jam listen-along.

**Download:** [APK](https://github.com/sunnysing1202/sadaiv-music/releases/download/v1.0.0/sadaiv-music.apk)

## Highlights

- Watch Together rooms with room codes and QR join for synced video playback
- Jam listen-along sessions with sync status and optional song file transfer
- Full playback suite: queue, shuffle, repeat, speed control, and sleep timer
- Synced LRC and plain lyrics with share options
- Ringtone tools: trim any song with waveform range, fade in/out, and save as ringtone/notification/alarm
- Audio effects: 10-band equalizer, presets, bass boost, and virtualizer
- Playlist import plus audio splitting for long mixes into tracks
- Home screen widget with now-playing controls
- Local library with songs, albums, artists, folders, playlists, and liked songs

## Quick start

1. Download the APK from the link above.
2. Install it on your device (enable Install unknown apps if prompted).
3. Grant media permissions so the app can read your local library.
4. Open the app and start playing.

## How to use

### Library

- Browse Songs, Albums, Artists, or Folders.
- Long-press a song to add it to a playlist or queue.
- Use Liked Songs to collect your favorites.

### Player

- Use the mini player for quick controls.
- Open the full player for lyrics, queue, shuffle/repeat, speed, and sleep timer.

### Jam listen-along

- Open Jam from the player or Jam screen.
- Create a room and share the code.
- Join a room to sync playback with others.

### Watch Together

- Open Watch Together and pick a video.
- Share the room code or scan one to join.
- Playback stays synced across participants.

### Ringtone and alarm tools

- Open the ringtone cutter from a song.
- Drag the start/end handles to trim a long track.
- Toggle fade in/out, preview the selection, and save as ringtone, notification, or alarm.
- Optional: set as the default system tone (requires Modify system settings).

### YouTube ringtone cutter

- Paste a YouTube link, fetch the audio, and trim the section you want.
- Save it as a ringtone, notification, or alarm.
- Use only content you have rights to and follow platform terms.

### Playlist import and audio splitting

- Paste a playlist list or import a text file to match tracks.
- Select a long audio file and auto-split it into multiple tracks.
- Save the matched tracks as a new playlist.

### Equalizer and effects

- Enable the 10-band equalizer and pick a preset.
- Adjust bass boost and virtualizer for a wider sound.

## Requirements

- Android 8.0 or newer (API 26+)
- Storage access for local media
- Internet connection for Watch Together and Jam sessions

## Permissions

Some permissions are optional and only used for specific features.

| Permission | Reason |
| --- | --- |
| `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` | Read local music files |
| `READ_MEDIA_VIDEO` | Watch Together video selection |
| `RECORD_AUDIO` | Optional voice features |
| `INTERNET` | Online rooms and syncing |
| `POST_NOTIFICATIONS` | Playback notifications |
| `FOREGROUND_SERVICE` | Background playback |
| `MODIFY_AUDIO_SETTINGS` | Equalizer and audio effects |
| `WRITE_SETTINGS` | Ringtone setting |
| Bluetooth and Nearby permissions | Device discovery and local sessions |

## FAQ

**Why does it ask for so many permissions?**
Some features are optional. The core player only needs media access.

**Is my music uploaded?**
The app plays local files. Online features only use data needed to sync sessions.
